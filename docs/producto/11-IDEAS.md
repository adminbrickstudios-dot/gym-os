# Ideas para que Gym OS sea "wow"

Ordenadas por cuánto suman y cuánto cuestan. Las de **Ahora** entran a la
hoja de ruta; las de **Después** quedan para cuando el MVP esté vendido.

## Ahora (suman mucho, cuestan poco)

| Idea | Por qué es wow | Ítem |
|---|---|---|
| **Racha y entradas del mes** en la app ("🔥 12 entradas, 3 semanas seguidas") | El socio se engancha; el que no viene se nota | APP-7 |
| **Invitá a un amigo** (pase de prueba con su nombre; si se hace socio, premio configurable) | Crecimiento sin publicidad | REF-1 |
| **Página del gimnasio que vende sola**: planes con precio, horarios, fotos, "Hacete socio" y pago | Lo primero que ve un cliente nuevo del gimnasio | PAG + REG |
| **QR inverso en la puerta** (A4): una tablet vieja reemplaza un molinete de $2 millones | Ahorro enorme para el gimnasio chico | ENT-6 |
| **Resumen diario al dueño** con lo importante en 5 líneas | El dueño deja de preguntar | AVI-4 |
| **"Probá Gym OS" para vender**: el demo con datos reales de mentira, en un link | Mateo vende mostrando | ADM-5 |
| **Importar desde Excel en 1 minuto** | Saca la mayor excusa para no cambiar de sistema | SOC-1 |
| **Precio por medio de pago visible** para el socio | Transparencia, menos discusiones | PLA-5 |
| **Primeros pasos con progreso** | El dueño arranca solo, sin llamar a BRIK | ONB-1 |

## Después (grandes)

| Idea | Qué es |
|---|---|
| **Predicción de bajas** | Con la asistencia de cada socio, un puntaje de "se está yendo" antes de que deje de venir (sin datos de salud) |
| **Asistente para el dueño** | Preguntarle en castellano: "¿cuánto cobré en octubre por transferencia?", "¿quién no viene hace 2 semanas?" (con IA, solo lectura de sus datos) |
| **Rutinas con IA para el profe** | Arma una rutina base según objetivo y días; el profe la ajusta |
| **Ranking y desafíos** | Box: tablero de marcas del WOD; gimnasio: desafío del mes por asistencia |
| **Ocupación en vivo** | "Ahora hay 23 personas" en la página y la app (de las entradas) |
| **Panel de marca para franquicias** | Juntar los números de todas las sedes de una marca |
| **Tienda online** | Suplementos y ropa del gimnasio con retiro en recepción |
| **Facturación electrónica ARCA** | Factura C/B automática por cada pago (integrador) |
| **Molinete y cerraduras** | Placa con relé que abre con el veredicto verde |
| **Entrada sin internet** | La recepción guarda quién puede entrar y sincroniza después |
| **Marketplace de clases** | Gimnasios de Gym OS ofrecen clases sueltas a socios de otros (como ClassPass) |
| **App con la marca propia en las tiendas** | Para cadenas que lo paguen |
