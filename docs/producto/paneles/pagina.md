# 🌐 Página del gimnasio

Lo primero que ve un cliente nuevo. Tiene que vender sola.

## Secciones (cada una se prende, se ordena y se edita, PAG-1)

1. **Portada**: logo, nombre, frase, foto o video, botones **💪 Hacete socio** (verde) y **Probá una clase**.
2. **Planes**: tarjetas con precio por medio de pago, qué incluye, "Elegir este" → alta online.
3. **Horarios**: de apertura y grilla de clases (si hay).
4. **Fotos**.
5. **Profes** (opcional): foto y especialidad.
6. **Cómo llegar**: dirección, mapa, sedes.
7. **Preguntas frecuentes** (las escribe el dueño).
8. **Contacto**: WhatsApp, Instagram.
9. Pie: "💪 Soy socio" (app) · "🛎️ Soy del equipo".

| Botón | Qué hace | Estado |
|---|---|---|
| Hacete socio / Elegir este | Alta online con pago (REG-1) | 🆕 |
| Probá una clase | Formulario corto → prospecto + pase de prueba (PAG-3, CLA-6) | 🆕 |
| WhatsApp | Abre chat con mensaje ("Hola, vi la página…") | ✅ |
| Soy socio | Ingreso del socio | ✅ |
| Compartir | Open Graph lindo al pegar el link (PAG-2) | 🆕 |

Sin publicar → "Próximamente" con WhatsApp y acceso de socios y equipo (✅).
Las opiniones o testimonios solo pueden ser reales (cargados por el dueño con nombre del socio y su permiso); nunca inventados.
